## مواصفات نهائية (Frontend فقط React) — “متحر هلا” — صفحة منتج مستقلة — بدون Backend/Admin

### 0) نطاق المشروع

* **React Frontend فقط** (Static).
* صفحات:

  * `/` الرئيسية
  * `/p/:slug` صفحة المنتج (مستقلة)
  * `/policies/privacy` `/policies/refund` `/policies/terms`
  * `/contact` (اختياري)
* **لا سلة حقيقية ولا دفع ولا تخزين طلبات**: زر “اطلب الآن” يعمل كالتالي:

  * **يفتح WhatsApp** برسالة جاهزة (مقترح) أو
  * يعرض صفحة “تم استلام طلبك (وهمية)” داخل الفرونت (اختياري)

---

## 1) Definition of Done (شروط التطابق)

### تطابق UI (مثل الصور)

* Top bar أسود + نص الشحن المجاني + أيقونة.
* Header أبيض Sticky: منيو يسار + سلة مع badge + اسم البراند يمين + علامة.
* Hero وسط الصفحة + زر أسود كبير.
* Banner صورة كبيرة.
* Features خلفية سوداء 2×2.
* Products Grid كروت بنفس الشكل (سعر قبل مشطوب + سعر بعد أحمر + زر أسود).
* FAQ Accordion.
* Footer أسود بنفس التقسيم.
* WhatsApp Floating أسفل يسار.

### تطابق PDP `/p/:slug`

* Breadcrumb.
* صورة كبيرة.
* Stars + عدد مراجعات.
* سعر قبل/بعد + badge خصم.
* “عرض محدود” indicator.
* Bundles (1/2/3) مع Tags “الأكثر مبيعًا/أفضل عرض”.
* فورم بيانات (اسم/جوال/عنوان…).
* زر CTA: `اطلب الآن - الدفع عند الاستلام`.
* Trust strip تحت الزر.
* Accordion سياسات.
* Reviews section كروت.

## 2) بيانات المحتوى (Static) — ملف واحد

### ملف البيانات المطلوب

`src/data/store.js` أو `store.json` يحتوي:

* brand_name = `متحر هلا`
* free_shipping_threshold_sar = `199`
* hero texts
* features
* products[] (كل منتج)
* faq[]
* footer links + contact

### نموذج المنتج (Product)

* `slug` (لرابط الصفحة)
* `name`
* `category`
* `price` (SAR)
* `compareAt` (SAR)
* `images[]` (روابط صور)
* `ratingAvg`
* `reviewsCount`
* `discountLabel` (مثال “خصم 50%”)
* `description`
* `reviews[]` (اختياري)

## 3) سلوك “الطلب” بدون Backend

### الخيار الموصى به (WhatsApp Order)

عند الضغط على **“اطلب الآن - الدفع عند الاستلام”**:

* يفتح رابط واتساب:

  * رقم ثابت (تعدله أنت)
  * رسالة تلقائية تشمل:

    * اسم المنتج
    * الباقة المختارة (1/2/3)
    * الإجمالي بالريال
    * بيانات العميل من الفورم (اسم/جوال/عنوان)

> هذا يعطيك تدفق طلب حقيقي بدون أي Backend.

### بديل (Success Page وهمية)

* تعرض “تم استلام طلبك” + رقم طلب عشوائي (Front فقط).

## 7) نسخة المحتوى السعودي (جاهزة)

### TopBar

* `شحن مجاني على الطلبات اللي تزيد عن 199 ر.س`

* `جودة المواد` — `منتجات مختارة بعناية`
* `دفع آمن` — `الدفع عند الاستلام متاح`
* `دعم العملاء` — `من الإثنين إلى السبت`

### CTA

* `اشتر الآن`
* `اطلب الآن - الدفع عند الاستلام`

### FAQ

* طرق الدفع: `الدفع عند الاستلام داخل السعودية.`
* الشحن: `عادة 2–5 أيام عمل داخل المملكة.`
* الإرجاع: `إرجاع سهل خلال 14–30 يوم حسب الحالة.`
* الإلغاء: `راسلنا واتساب برقم الجوال واسم المنتج.`

## 9) ما تحتاج ترسله الآن (حتى يكون مطابق 100%)

بدون أسئلة إضافية كثيرة—أرسل فقط:

1. **رقم واتساب السعودي** الذي سيستقبل الطلبات
2. **شعار البراند** (PNG/SVG) إن وجد
3. **قائمة 6–12 منتج** (اسم + سعر + سعر قبل + صور)

إذا لم ترسل، سيتم وضع قيم افتراضية (placeholder) ويمكنك تغييرها من ملف البيانات لاحقًا.
